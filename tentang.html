Tentang Website

Apa itu Jogja Wisata?

Jogja Wisata adalah website informasi wisata yang menyajikan data destinasi budaya, alam, serta belanja dan kuliner di Daerah Istimewa Yogyakarta. Website ini dibuat sebagai tugas mata kuliah Pemrograman Web menggunakan HTML, CSS, Bootstrap 5, dan JavaScript.

Tujuan

  • Memudahkan wisatawan mencari informasi destinasi.
  • Memperkenalkan potensi wisata daerah.
  • Menjadi sarana belajar pengembangan website statis.
